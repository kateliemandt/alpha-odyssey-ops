# Alpha Odyssey — Ops Manual

The operational backend for Alpha Odyssey Summer 2026. A ship captain's manual, not a parent brochure.

## Sections

1. **Daily Flow of Events** — three schedule variants (regular, Friday test, Monday launch)
2. **Master Supplies List** — every material for 9 weeks + 53 side quests, with Amazon search links
3. **Things to Make / Fluo Can Make** — custom builds, pre-summer prep, Fluo shop orders
4. **Merch & Odyssey Design** — wax seals, logbooks, badges, level gear, design language
5. **Bussing / Transportation** — 10 venues, drive times, weekly bus requirements
6. **Vendor List** — Fluo, 13 specialists, 7 venue partners, status tracking
7. **Permits Needed** — 14 permits/waivers with authority, timeline, priority
8. **AI Integration Guide** — generative AI, recording/transcription (Plaud), ops automation
